# Roadmap

## Done in 3.0

- Paths for a goal (CCNA 200-301, SWE internship, CS fundamentals, web development, security, math),
  with blueprint-weighted stages, labs, challenge sets, projects and a readiness score
- Interactive lessons: 36 activity types (algorithm visualizers, data structure playgrounds, logic and
  CPU scheduling, regex, HTTP, git, a Linux terminal, and networking simulators from subnetting to OSPF)
- A simulated Cisco IOS console with multi-device labs and troubleshooting scenarios, rescheduled by FSRS
- Coding challenges in JavaScript and Python with hidden tests, staged hints and reference solutions
- New question types: select all, put in order, match pairs, type the command
- Quizzes with instant feedback and timed practice exams scored at the end
- Pop quizzes, lesson warm-ups, recall roulette, and redo scheduling for labs and challenges
- Ways to learn: research summary, approach quiz, a recall experiment and per-approach results
- Feynman rounds with audiences, follow-up questions and an offline self-check
- Guided projects and a portfolio page that exports to Markdown
- Sound, particles, combos and celebrations with three effect levels; ten themes and adjustable accents
- CCNA content rewritten from the official blueprint, SWE content for interview patterns through
  getting hired, and every existing topic reviewed and deepened

## Done in 2.0

- Study engine rebuilt on FSRS: due reviews first, new cards in lesson order, daily new-card limit,
  in-session retries, interleaved daily review, accurate interval previews, undo
- Pack builder with bulk paste (Quizlet and Anki exports), JSON import, AI generation
- Progress page: forecast, activity, memory by topic, accuracy by type, mistake journal
- Keyboard shortcuts, mobile layout, offline PWA with bundled fonts
- Storage v2 with automatic migration and backups
